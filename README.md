# 📚 Economics Teaching & Learning Tools / 经济学教学与学习工具

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-live-2ea44f)](https://xyjiapku.github.io/economics_mini_lab/)
[![License: CC0-1.0](https://img.shields.io/badge/License-CC0--1.0-lightgrey)](LICENSE)
[![No Build Required](https://img.shields.io/badge/build-none-purple)](https://xyjiapku.github.io/economics_mini_lab/)

Interactive simulations, visual derivations and study aids for **IGCSE, IB, A-Level, AP and introductory university** economics courses. All tools are **single-file HTML** — open them in any browser, no installation or build step required.

面向 **IGCSE、IB、A-Level、AP 及大学入门经济学**课程的互动模拟、可视化推导与学习工具。所有工具均为**单文件 HTML**——用任意浏览器打开即可,无需安装、无需构建。

## 🌐 在线访问 / Online Access

**https://xyjiapku.github.io/economics_mini_lab/**

The index page provides search, category filters and one-click access to every tool. 首页提供搜索、分类筛选与一键访问所有工具。

## ✨ 功能特色 / Features

- **互动模拟与可视化** / Interactive simulations & visualisations — 滑杆、拖拽、实时图表 (Chart.js)
- **游戏化学习** / Gamified learning — 回合制博弈、计分、排行榜、即时反馈
- **分步推导** / Step-by-step derivations — 从数据表到最优解的完整推理路径
- **课堂友好** / Classroom-ready — 支持投影演示与小组活动,纯前端、无后端依赖
- **双语教学可用** / Suitable for bilingual teaching — 界面以英文为主,便于国际课程使用

## 🚀 使用方式 / How to Use

**在线使用 / Online:** 直接访问 GitHub Pages 首页,搜索或按分类筛选工具。 打开任意工具页面,按照「Step-by-Step Theory → Simulator」的流程体验完整的推导与互动。

**本地使用 / Local:** 下载本仓库 ZIP(Code → Download ZIP),解压后双击 `index.html` 即可离线使用全部工具(推荐用 Chrome / Edge / Firefox 打开)。
