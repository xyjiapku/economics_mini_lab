About This Site / 关于本站

中文 · 关于本站

这是一个面向 IGCSE、IB、A-Level、AP 及大学入门经济学课程设计的互动教学工具集。所有工具均为单文件 HTML,由 Chart.js 驱动,支持滑杆调节、拖拽操作、分步推导与游戏化互动。

  • 在线使用:在首页搜索或按分类(基础 / 微观 / 宏观 / 进阶)筛选,点击卡片进入对应工具。
  • 本地使用:下载本仓库 ZIP,解压后双击 index.html 即可离线使用全部工具,无需安装或联网。
  • 课堂友好:适合投影演示、小组活动与自主复习;界面以英文为主,便于国际课程教学。
  • 反馈建议:任意工具页面底部内置反馈表单,你的意见将直接帮助改进这些工具。

本项目以 CC0-1.0 许可发布,可自由使用、修改与分发(仅限教育用途,请勿商业再分发)。

English · About This Site

A collection of interactive teaching tools for IGCSE, IB, A-Level, AP and introductory university economics courses. Every tool is a single-file HTML page powered by Chart.js — with sliders, drag interactions, step-by-step derivations and gamified activities.

  • Online use: search or filter by category (Fundamentals / Micro / Macro / Advanced) on this page, then open any tool from its card.
  • Local use: download the repository as a ZIP, unzip it and open index.html — everything works offline, no installation or build required.
  • Classroom ready: designed for projection, group activities and self-study; the interface is in English, suitable for international programmes.
  • Feedback: each tool page includes a built-in feedback form — your suggestions directly shape future updates.
