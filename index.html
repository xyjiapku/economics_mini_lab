About This Site / 关于本站

中文 · 关于本站

这是一个面向 IGCSE、IB、A-Level、AP 及大学入门经济学课程设计的互动教学工具集。每个工具都是一个独立的交互页面，由 Chart.js 驱动，支持滑杆调节、拖拽操作、分步推导与游戏化互动。工具通过 vibe coding 构建，希望能帮助你直观理解核心概念、开展思想实验、巩固对关键模型的掌握。

  • 使用方式：在首页搜索或按分类（基础 / 微观 / 宏观 / 进阶）筛选，点击卡片进入对应工具。
  • 课堂友好：适合投影演示、小组活动与自主复习；界面以英文为主，便于国际课程教学。
  • 反馈建议：任意工具页面底部内置反馈表单，你的意见将直接帮助改进这些工具。

本项目为教学用途所建，仅供教育使用，请勿商业再分发。

English · About This Site

A collection of interactive teaching tools for IGCSE, IB, A-Level, AP and introductory university economics courses. Each tool is an interactive page powered by Chart.js — with sliders, drag interactions, step-by-step derivations and gamified activities. The tools were built through vibe coding; I hope you find them useful to visualise core concepts, run thought experiments, and reinforce your understanding of key models.

  • How to use: search or filter by category (Fundamentals / Micro / Macro / Advanced) on this page, then open any tool from its card.
  • Classroom ready: designed for projection, group activities and self-study; the interface is in English, suitable for international programmes.
  • Feedback: each tool page includes a built-in feedback form — your suggestions directly shape future updates.

Built for teaching purposes — for educational use only. Not for commercial redistribution.
